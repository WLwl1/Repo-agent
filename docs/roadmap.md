# Roadmap

Repo Agent's public roadmap is organized around trust, reach, and usability.

## 0.1: Launch Quality

- deterministic repository QA and bug localization
- local web studio
- HTML reports
- bundled eval fixtures
- CI running compile, eval, JS syntax checks, and pytest
- generated-artifact filtering for indexes and cache signatures

## 0.2: Benchmark Credibility

- 50-100 public localization cases
- regression fixtures for parser edge cases
- benchmark report generator
- failure gallery in docs
- versioned eval datasets

## 0.3: Language Reach

- better TypeScript route and import handling
- React component and event-surface detection
- Go HTTP route detection
- Ruby/Rails route detection
- configurable ignore patterns

## 0.4: Product Polish

- screen recording and launch demo
- installable package with packaged web assets
- richer report links from evidence to source
- keyboard-friendly Studio navigation
- saved investigation history

## 0.5: Integration Layer

- export evidence bundles for other coding agents
- GitHub issue triage workflow
- optional embedding provider adapters
- machine-readable report schema
